# Gmarciani

![GMARCIANI Logo](src/images/logo/gm-logo.svg)

Personal blog at [gmarciani.github.io](https://gmarciani.github.io).

## Requirements

Install Node.js 24:

```shell
nvm install 24
```

Install Hugo and ImageMagick:

```shell
brew install hugo imagemagick
```

Install project dependencies:

```shell
npm install
```

Check updates for project dependencies:

```shell
npx npm-check-updates -u
```

## Usage

Build:

```shell
npm run build
```

Serve the website:

```shell
npm run serve
```

Enable Gulp watching to live preview changes:

````shell
npm run watch
````
