# Product

Personal technical blog for Giacomo Marciani, hosted at [gmarciani.github.io](https://gmarciani.github.io).

The blog covers HPC, distributed systems, cloud infrastructure, security, web applications, leadership, and personal projects. Content is written in a direct, opinionated, practitioner-first style — long-form technical posts and short quotings aimed at engineers.

The site is a static Hugo blog with a custom theme built from Pug templates, SCSS styles, and a Gulp-based asset pipeline.
