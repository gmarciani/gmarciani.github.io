# Project Structure

```
├── config.yaml              # Hugo site configuration
├── gulpfile.js              # Gulp asset pipeline tasks
├── package.json             # Node.js dependencies and scripts
├── archetypes/              # Hugo content templates (default front matter)
│   └── default.md
├── content/                 # All site content (Markdown)
│   ├── about.md             # About page
│   └── posts/               # Blog posts organized by category
│       ├── academic/
│       ├── ai/
│       ├── aws/
│       ├── hpc/             # Largest series (19 posts, numbered)
│       ├── leadership/
│       ├── my-projects/
│       ├── security/
│       └── web-applications/
├── src/                     # Source assets (processed by Gulp)
│   ├── fonts/               # Custom fonts (BebasNeue, ColorTube, Dekar, etc.)
│   ├── images/              # Brand assets and post images
│   ├── meta/                # manifest.json, robots.txt, msconfig.xml
│   ├── scripts/             # JS source files
│   ├── styles/              # SCSS source (main.scss entry point)
│   └── views/               # Pug templates (compiled to layouts/)
├── layouts/                 # Hugo layouts (GENERATED from src/views by Gulp)
├── static/                  # Static assets (GENERATED from src/ by Gulp)
├── public/                  # Final site output (GENERATED by Hugo)
└── resources/               # Hugo resource cache (GENERATED)
```

## Key Conventions

- `layouts/`, `static/`, `public/`, `resources/` are all generated — never edit directly. Source of truth is `src/` and `content/`.
- Blog posts live in `content/posts/{category}/`. Each category has an `_index.md` that sets the category taxonomy via `cascade`.
- HPC series posts are numbered with a two-digit prefix: `01-topic-slug.md`, `02-topic-slug.md`, etc.
- Post front matter fields: `title`, `description`, `date` (YYYY-MM-DD), `draft` (boolean), and optionally `image`.
- Hugo cross-references use `{{< ref "path.md" >}}` shortcode syntax.
- New posts default to `draft: true` (see `archetypes/default.md`).
